The project is modified from React Tutorial https://reactjs.org/tutorial/tutorial.html.

The followings are added.
1. Computer Player (using minimax)
2. Game Control.
   a. Play as O or X.
   b. Which player play first.

## Scripts

- `npm start`: run the Vite development server.
- `npm run build`: create a production build in `dist`.
- `npm test`: run Jest tests (`--passWithNoTests` enabled).
- `npm run deploy`: publish `dist` via `gh-pages`.
